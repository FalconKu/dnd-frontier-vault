# 霜脊边地

《龙与地下城》5e（2024 规则）。灰砧镇靠铁锭和过山商队活着。矿被封了，商队迟了十九天，冬天还有三个月。

- **人数**：沙盒资源包
- **时长**：可支撑 2–3 次团
- **结构**：无冒险节点（资源包）
- **内容**：世界书 27 条（12 条公开 / 15 条守秘人专属），地图地点 9 个

## 结构

| 部分 | 内容 |
|---|---|
| 九个地点 | 断镐酒馆、议事厅、铁匠铺、河磨坊、半身人神龛、货栈马厩、矿口、北岭瞭望塔、石桥 |
| 三方势力 | 矿主管钱、镇务官管契约、半身人商会管货源 |
| 两条线 | 下矿（接《余烬金库》）与过山口（接《霜语渡口》） |

## 守秘人要点

1. **这是沙盒底子，不是剧本。** 九个地点足够跑一场「镇子要不要继续送人过山口」的政治戏。

2. **配《余烬金库》跑最顺。** 世界用这里的 `ashfell`，冒险推荐 `ashfell_ember` 是同一地点「矿封之后」的版本。两个都装，灰砧镇就完整了。

3. **不要一上来就讲「名字」的机制。** 让玩家先看见空马厩和回来的货，自己问「人呢」。

## 这个模组在讲什么

结构性压力：山口每年只有五到九月能过。不封矿就要送人清账，封了矿就要送人过山口——两边都要人。今年无论怎么选都要死人。
